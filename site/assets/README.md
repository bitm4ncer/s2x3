# Site assets

- `background.jpg` is original art generated for s2x3 with
  `openrouter/google/gemini-nano-banana-2.1`.
- `launcher.webp` and `launcher.png` are screenshots of the launcher.
- `icon.png` is the S2X3 app icon, generated from
  `.design/s2x3_AppIcon.png`.
- `platform-icons.svg` holds the small Windows, macOS and Linux glyphs used by
  the download buttons.
- The `S2X3` wordmark and headings are set in **Tomorrow Black Italic**,
  bundled in `assets/fonts/` under the SIL Open Font License 1.1. Pixel labels
  use **Silkscreen** (OFL) through Google Fonts.
