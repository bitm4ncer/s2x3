# Site assets

- `background.jpg` is original art generated for slope3 with
  `openrouter/google/gemini-nano-banana-2.1`.
- `launcher.webp` and `launcher.png` are screenshots of the launcher.
- The `slope3` wordmark and the big `3` are inline SVG outlines generated
  from **Alpino Bold** by Indian Type Foundry, used under the ITF Free Font
  License. The font file itself is not committed; the page loads Alpino Bold
  through the Fontshare API. The license allows wordmarks and vector files
  created with the font.
