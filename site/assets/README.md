# Site assets

- `background.jpg` is original art generated for s2x3 with
  `openrouter/google/gemini-nano-banana-2.1`.
- `launcher.webp` and `launcher.png` are screenshots of the launcher.
- `platform-icons.svg` holds the small Windows, macOS and Linux glyphs used by
  the download buttons.
- The `s2x3` wordmark and headings are set in **Alpino Bold**, loaded through
  the Fontshare API. The font file itself is not committed. The ITF Free Font
  License allows this use. Pixel labels use **Silkscreen** (OFL) through Google
  Fonts.
