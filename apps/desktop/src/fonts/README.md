# Fonts

`Tomorrow-BlackItalic.ttf` is bundled under the SIL Open Font License 1.1
(see `OFL.txt`). It replaces the personal-use Archie Pro Italic as the
launcher's display face and matches the front page.

A local `ArchiePro-Italic.ttf` may remain in a checkout for reference, but it
is ignored by git and is no longer loaded by the UI.
